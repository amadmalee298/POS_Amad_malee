# บัญชีส่วนตัว (Personal Finance)

เว็บแอปบันทึกรายรับ–รายจ่ายส่วนบุคคล พร้อมแดชบอร์ดสรุปรายเดือน — ไฟล์เดียว (`index.html`) ไม่ต้องติดตั้ง ไม่ต้องมีเซิร์ฟเวอร์

## ฟีเจอร์

- **แดชบอร์ดสรุป**: รายรับ, รายจ่าย, คงเหลือสุทธิ, อัตราการออม พร้อมเปรียบเทียบกับเดือนก่อน
- **กราฟรายรับ vs รายจ่าย** ย้อนหลัง 6 เดือน (เอาเมาส์ชี้เพื่อดูยอดและคงเหลือ)
- **รายจ่ายตามหมวดหมู่** เรียงจากมากไปน้อย พร้อมสัดส่วน %
- **งบประมาณรายเดือน** แถบแสดงการใช้เงิน และแจ้งเตือนเมื่อใกล้/เกินงบ
- เพิ่ม / แก้ไข / ลบรายการ, ค้นหาและกรองตามประเภท, เลือกดูทีละเดือน
- หมวดหมู่สำเร็จรูป หรือพิมพ์หมวดใหม่เองได้
- **ส่งออก CSV** (เปิดใน Excel ภาษาไทยได้), **สำรอง/กู้คืน** ข้อมูลเป็นไฟล์ JSON
- โหมดสว่าง/มืด และรองรับมือถือ

## วิธีใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้ทันที หรือเปิด GitHub Pages ของ repo นี้

ข้อมูลทั้งหมดเก็บไว้ในเบราว์เซอร์ของคุณ (localStorage) เท่านั้น — ไม่ถูกส่งไปที่ใด
แนะนำให้กด **สำรอง** เป็นระยะ เพราะการล้างข้อมูลเบราว์เซอร์จะทำให้ข้อมูลหายได้
